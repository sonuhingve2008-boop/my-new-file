README   FILE


1. Introduction

This project is a simple Python-based calculator that performs basic mathematical operations. The calculator gives users multiple options like addition, subtraction, multiplication, division, square, cube, square root, power, and percentage. The program runs continuously until the user chooses to exit.

2. Objective

To create an easy and interactive calculator using Python.

To help users perform mathematical calculations through a simple menu-driven 
program.

To practice the use of loops, conditions, functions, and mathematical operations.


3. Tools  &  Technologies  Used

Python Programming Language

Built-in math module for square root function.

IDE / Code Editor (VS Code, IDLE, PyCharm, etc.)


4. Program Description

The calculator displays a menu with options from 1 to 0. The user selects an option, enters the required number(s), and the program shows the result.
It uses :

while loop to run continuously

if-elif-else statements to handle different choices

math.sqrt() for square root


When the user enters 0, the program stops.

5. Features   of  the  program

1. Addition


2. Subtraction


3. Multiplication


4. Division (with zero error handling)


5. Square of a number


6. Cube of a number


7. Square root of a number (negative number error handling)


8. Power calculation


9. Percentage calculation


10. Exit option

6. Working  of  the  Program

The program first prints a menu.

Then it asks the user to enter a choice from 1 to 0.

Based on the input, it performs the selected operation.

The program continues running until the user enters 0.
